# Weather Dashboard

A real-time weather dashboard built with Python and Streamlit, powered by the OpenWeatherMap API.

## Features
- Current weather conditions (temperature, humidity, wind speed)
- 5-day forecast with temperature trend chart
- Extreme weather alerts
- Search history

## Tech Stack
Python, Streamlit, OpenWeatherMap API, Pandas

## Setup
1. Install dependencies
```bash
   pip install -r requirements.txt
```
2. Add OpenWeatherMap API key in `.env`
```
   API_KEY=your_key_here
```
3. Run
```bash
   streamlit run main.py
```
